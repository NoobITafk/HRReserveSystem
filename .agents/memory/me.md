# Developer Profile & Project Conventions

- **Language:** 100% pure professional Ukrainian language for all UI elements, labels, notifications, and audit messages. No Russianisms or awkward machine translations.
- **Tone & Style:** Smart Brevity, military BLUF, absolute honesty, zero flattery or inflated scores.
- **Design Aesthetic:** Clean Scandinavian / Swiss minimalism (Linear, Notion, Apple iOS style). Crisp borders (`border-subtle`), high contrast, subtle muted tones, soft badges (`badge-soft-*`), smooth transitions without distracting animations.
- **Theme Support:** Full light and dark theme synchronization (`data-theme="light"` and `"dark"`).
- **Quality Iron Law:** Zero broken builds (`dotnet build`), zero failing tests (`dotnet test`) after any change. Fresh verification evidence required before claiming completion.
