# Інструкції для агентів (HR Reserve System)

Працюй із цим проєктом за стандартами **OpenAI Developer Guidelines** та чистим .NET 8 / UI/UX стеком.

## Основні правила:
1. **Не переписуй проєкт з нуля.** Зберігай робочу структуру, архітектуру та існуючі контролери.
2. **Не ламай існуючу логіку:**
   - Ролі: `Admin`, `Recruiter`, `Interviewer`.
   - Seed data та демо-акаунти (`admin`, `recruiter`, `interviewer` з паролями `admin123`, `recruiter123`, `interviewer123`).
   - SQLite для локальної розробки, PostgreSQL для продакшену/VPS.
3. **UI та презентаційний вигляд:**
   - Інтерфейс має бути преміальним, чистим (Scandinavian / Swiss minimalism), адаптивним і зрозумілим будь-якому клієнту чи рекрутеру.
   - Повноцінна підтримка світлої та темної теми (data-theme="light" / "dark").
   - Всі тексти — чистою, професійною українською мовою.
   - Красиві бейджі статусів, метрики, графіки, порожні стани (empty states).
   - Швидкий демо-вхід в 1 клік на сторінці логіну для кожної ролі.
4. **Якість коду та перевірка:**
   - Після кожної зміни обов'язково запускай `dotnet build` та `dotnet test`.
   - Жодних невиправлених помилок компіляції або падаючих тестів.
   - Після завершення реалізації залучай незалежних субагентів для ретельного зовнішнього тестування інтерфейсу та функціоналу.
